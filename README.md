# 🚀 Tech Amigos Landing Page

A modern, responsive landing page designed for the **Tech Amigos Club**. The website showcases the club's events, current and past members, achievements, and social media presence with smooth animations and an interactive user interface.

## 🌐 Live Demo

**Website:** https://chotu.free.nf

---

## 📌 Features

- 🎨 Modern and responsive UI
- 📱 Mobile-friendly design
- ✨ Smooth animations and transitions
- 📸 Event showcase slider
- 👥 Current members section
- 🏆 Past members gallery
- 🍔 Animated sidebar navigation
- 🌌 Interactive background effects
- 📲 Social media integration

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Font Awesome Icons

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/<your-username>/TechAmigos_landing_page.git
```

### 2. Open the project

```bash
cd TechAmigos_landing_page
```

### 3. Run

Simply open **index.html** in your browser.

Or use **VS Code Live Server** for the best experience.
